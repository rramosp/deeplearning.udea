## Course outline

### 1. Introduction (2 semanas teoría + 1 semana de laboratorio)

### 2. Loss functions (1 semanas de teoría + 1 semana de laboratorio)

### 3. Classical Deep Learning Architectures (2 semana de teoría + 1 laboratorio)

### 4. Attention is all you need (3 semanas + 1.5 laboratorio)

### 5. Transformers in practice (2 semanas de teoría + 1.5 laboratorio)

### total: 10 semanas de teoría y 6 de laboratorios
